# ToDoList App

Десктопное приложение для управления списком дел с возможностью установки дедлайнов, сортировки, редактирования и визуального отслеживания срочности задач.

## Функции

*   **Добавление задач:** Введите название задачи и выберите дедлайн.
*   **Редактирование задач:** Откройте подробности задачи и отредактируйте содержимое.
*   **Отметка выполнения:** Отметьте задачу как выполненную.
*   **Удаление задач:** Удалите ненужные задачи.
*   **Сортировка:** Сортируйте задачи по названию, статусу, дате создания или дедлайну, кликая на заголовки столбцов.
*   **Визуализация дедлайнов:**
    *   Ячейка дедлайна **жёлтая**, если до дедлайна осталось 1-2 дня.
    *   Ячейка дедлайна **красная**, если дедлайн сегодня или просрочен.
    *   Ячейка дедлайна **зелёная**, если задача отмечена как выполненная.
*   **Сохранение данных:** Задачи сохраняются в локальный файл `files/todolist.json`.

## Установка

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/DmitriyVish/ToDoList_PyQt6.git
    cd ToDoList
    ```

2.  **Создайте и активируйте виртуальное окружение:**
    ```bash
    python -m venv venv
    source venv/bin/activate  # На Linux/macOS
    # или
    venv\Scripts\activate     # На Windows
    ```

3.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```
    *(Если файла `requirements.txt` нет, установите вручную: `pip install PyQt6`)*
